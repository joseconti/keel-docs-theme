# Maintenance commands

Development-only helpers are excluded from release archives. `keel-time` records start, slice-start, slice-end, pause/resume and end; `keel-clock` is the canonical measured-event engine. `keel-plan [--check]` generates/checks docs/.keel/plan.json. `keel-handoff-verify [--release]` validates the ignored continuation courier. `keel-verify` runs bounded maintenance/runtime checks. `keel-affected-tests --run [--full]` selects runtime checks for changed theme/demo/scripts paths. `keel-close` performs the scoped branch close and writes a fresh handoff; publication is separately controlled by the coordinator. `keel-stop-hook` is available but not registered for an unconfirmed tool contract. `keel-parallel` is the canonical assignment coordinator; this issue executes serially. `verify-reflow.cjs` needs Node, Puppeteer Core (PUPPETEER override) and Chrome (CHROME override), keeps fixtures temporary and makes no external requests.
